# Dungeonfall

Пиксельный roguelike-шутер на Python и Pygame CE. Искатель и Дозорная спускаются через 15 процедурных этажей и сражаются с тремя хранителями подземелья. Игра рисуется на сетке 640×360, которая масштабируется без сглаживания. **F11** переключает полноэкранный режим.

## Запуск

На Windows распакуй архив и запусти **Play-Dungeonfall.cmd**. Для него нужен Python 3.14. Скрипт создаст виртуальное окружение, установит Pygame CE и откроет игру. При первой установке зависимости нужен интернет.

На Ubuntu открой терминал в папке с `main.py` и `requirements.txt` и выполни:

```bash
sudo apt update
sudo apt install -y python3-full
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

При повторных запусках достаточно `.venv/bin/python main.py`. Если предпочитаешь установленный отдельно Python 3.14, подставь `python3.14` вместо `python3` при создании окружения. Сборка проверена с Python 3.14.7 и Pygame CE 2.5.8.

## Управление

| Ввод | Действие |
|---|---|
| WASD или стрелки | Движение |
| Мышь, ЛКМ | Прицеливание и стрельба |
| ПКМ | Удар клинком в направлении курсора. Работает с пустым магазином и во время перезарядки |
| R | Перезарядка |
| E | Открыть ворота или сундук, взять оружие |
| 1 и 2 | Сменить оружие или выбрать слот для находки |
| Esc, F11 | Пауза, полноэкранный режим |

## Подземелье и бои

Каждая локация занимает пять этажей. На этаже 5–8 связанных комнат и 1–2 сундука. В боевых залах и на аренах есть стены и ящики, которые останавливают персонажей и снаряды. Мини-карта отмечает игрока красной точкой, неизученные комнаты серым, а посещённые цветом локации.

В первой волне боевой комнаты 4–8 врагов. С вероятностью 50% к ним приходит подкрепление из 3–5 врагов. Перед атакой у противника появляется красный пиксельный знак. **Рыскарь** заходит с фланга и делает рывок по зафиксированному направлению. **Призма** выпускает прямой и два изогнутых снаряда. **Оракул** по очереди подрывает две заранее отмеченные области.

У обычных врагов один бросок за добычу. **Патроны выпадают с шансом 5,5%, аптечка с шансом 4,5%.** Спуск на следующий этаж возвращает до 55 здоровья, переход в новую локацию после босса восстанавливает здоровье полностью.

| Локация | Босс на пятом этаже | Особенности боя |
|---|---|---|
| Моховая роща | Терновый олень | Рывок, шипы, цепочка ударов по земле, направленный луч |
| Янтарные катакомбы | Печник | Залпы в два слоя, взрывы по сторонам от игрока, расходящиеся лучи |
| Ледяные руины | Ледяная королева | Перекрёстный обстрел, отложенные ледяные зоны, разнонаправленные лучи |

У каждого босса пять атак. На половине здоровья босс атакует чаще, а в отдельных атаках появляются дополнительные снаряды, зоны или лучи. Опасные участки размечаются до удара. У локаций и боссов по три разных оригинальных музыкальных темы, которые переключаются при входе в бой и его завершении. Громкость музыки и эффектов регулируется отдельно.

## Арсенал

Герой стартует с «Искрой». У всех 15 видов оружия своя механика. При подборе игра показывает её в окне выбора слота.

| Оружие | Механика |
|---|---|
| Искра | Каждое попадание подряд в одну цель усиливает урон. Промах или смена цели сбрасывают серию |
| Осколок | Пять осколков по разу рикошетят от стены или края арены. Отскок усиливает урон |
| Импульс | При удержании ЛКМ темп стрельбы постепенно растёт |
| Струна | Разряд перескакивает на соседних врагов, если между ними есть прямая видимость |
| Жаровня | Снаряд оставляет огонь на полу. Цели в зоне получают повторный урон |
| Рапира | Удерживай ЛКМ, чтобы зарядить мощный пробивающий выстрел |
| Саранча | Снаряды доворачивают к ближайшей видимой цели перед собой |
| Иней | Три попадания подряд замораживают обычного врага. Боссы ненадолго замедляются |
| Кувалда | Навесной снаряд перелетает укрытия и с задержкой взрывается в точке прицела |
| Циркуляр | Диск пробивает врагов и возвращается к герою, нанося урон на обратном пути |
| Трезубец | Выпускает один снаряд. Через долю секунды он разделяется на три |
| Картечь | Наносит больше урона в упор, распыляет дробь и отбрасывает героя отдачей |
| Комета | На дистанции снаряд разгоняется и наносит больше урона |
| Затмение | Создаёт воронку, которая стягивает обычных врагов, а затем схлопывается |
| Уголёк | Третье быстрое попадание по одной цели взрывает накопленные метки |

Ворота и сундуки разблокируются после последней волны. Когда откроешь сундук, дождись, пока добыча приземлится рядом. Сохранение хранит начало текущего этажа, параметры героя и оба слота оружия. Файл сохранения находится в `config/profile.json`.

<details>
<summary>Пасхалка с секретным боссом</summary>

Начни игру и нажми по очереди клавиши `6KOILMI6`. Регистр не важен, отдельного поля ввода нет. Герой перенесётся на отдельную арену с тем же набором оружия. Перед боем здоровье восстанавливается, а магазины пополняются.

У Демона разлома **71 000 здоровья**, в 50 раз больше, чем у Ледяной королевы. Он проходит три фазы и использует десять атак, в том числе таран, спирали снарядов, лучи и метеоры. После серии атак ненадолго открывается ядро, и демон получает усиленный урон. Победа над ним сразу завершает прохождение. После поражения можно загрузить начало последнего обычного этажа.

## Файлы и кадры игры

- `main.py` — вся игровая логика.
- `assets/` — спрайты, анимации, окружение, интерфейс, звуки и музыка.
- `config/defaults.json` — настройки по умолчанию.

В обновлённой сборке повторно пройдены все 15 обычных этажей. Отдельно проверены 15 механик оружия, ввод кода, три фазы демона и переход к экрану победы.
